Documentation

  
Munora is a dynamically typed toy programming language, based on the Bogura dialect, written in JavaScript.


    
General

    
Program shuru hoy ayen vai diye, shesh hoy ashi vai diye. Er baire ja likha thakbe, ignore hobe.

Variables

    
Variable banate dhor re lekho. a++ ar a-- diye 1 kore baratano ba komano jay.


ayen vai
  dhor re a = 10;
  dhor re b = "dui";
  dhor re c = 15;
  a = a + 1;
  c *= 2;
  a++;
  bol na a, b, c;
ashi vai


  
Types

    
Number ar string ager moto. faka mane null, thik ar bhul mane true ar false.


ayen vai
  dhor re a = 10 + (15 * 20);
  dhor re b = "Bogura";
  dhor re c = 'ok';
  dhor re d = faka;
  dhor re e = thik;
  dhor re f = bhul;
  bol na a, b, c, d, e, f;
ashi vai


  
Print

    
Output dekhate bol na. Comma diye ekadhik jinis dewa jay.


ayen vai
  bol na "Ki khobor";
  dhor re a = 10;
  {
    dhor re b = 20;
    bol na a + b;
  }
  bol na 5, 'ok', faka, thik, bhul;
ashi vai


  
Conditionals

    
jodi dekh = if, nahoy jodi dekh = else if, nahoy dekh = else.


ayen vai
  dhor re a = 10;
  jodi dekh (a < 5) {
    bol na "choto";
  } nahoy jodi dekh (a < 20) {
    bol na "moddhom";
  } nahoy dekh {
    bol na "boro";
  }
ashi vai


  
Loops

    
While

    
jotokkhon dekh: shorto thik thakle body bar bar chole.


ayen vai
  dhor re i = 1;
  jotokkhon dekh (i <= 5) {
    bol na i;
    i += 1;
  }
ashi vai


    
Do-while

    
age kor diye body ekbar cholbei, tarpor jotokkhon dekh diye shorto dekha hoy. Shorto shuru-te mithya hole-o body ekbar chole.


ayen vai
  dhor re i = 10;
  age kor {
    bol na "i =", i;
    i += 1;
  } jotokkhon dekh (i < 5);
ashi vai


    
For

    
ghur re: shuru, shorto, update tin ta jinis ; diye alada kore lekho.


ayen vai
  dhor re jog = 0;
  ghur re (dhor re i = 1; i <= 5; i++) {
    jog += i;
  }
  bol na "1 theke 5 er jog:", jog;
ashi vai


    
Break ar continue

    
thama re loop theke ber kore dey (break), porer ta dekh oi ghurta bad diye porer ghurte jay (continue).


ayen vai
  dhor re a = 0;
  jotokkhon dekh (a < 10) {
    a += 1;
    jodi dekh (a == 5) {
      bol na "pachh", a;
      porer ta dekh;
    }
    jodi dekh (a == 8) {
      thama re;
    }
    bol na a;
  }
  bol na "sesh";
ashi vai

  


  
Functions

    
kaj kor diye function banao, ferot de diye fol ferot dao. Function nijeke nijei dakte pare (recursion).


ayen vai
  kaj kor boro(a, b) {
    jodi dekh (a > b) {
      ferot de a;
    }
    ferot de b;
  }

  kaj kor factorial(n) {
    jodi dekh (n <= 1) {
      ferot de 1;
    }
    ferot de n * factorial(n - 1);
  }

  bol na boro(10, 25);
  bol na "5! =", factorial(5);
ashi vai
